CellNav

A navbar of cells. You describe it by chaining calls; each call returns a new builder, and .spec() gives you the plain data it built. Every example below shows the code that produced it.

cellNav(items)Items→ .layout(…)turns Items into Shapes→ .fill(…)what goes in each Shape→ .margin / .palettelook→ .mount(el, font)draw as SVG
Not built yet: hover / active / keyboard behavior (.behave(…)), image fills, aspect pull, single-shape text, nested layouts, and the <cell-nav> tag. Today every cell is a plain link.
